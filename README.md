# PatentDSL

PatentDSL は、特許明細書で使用する図面をテキストから作成する単一 HTML ツールです。

DSL は Domain-Specific Language の略で、特定用途のための記述言語を意味します。本ツールでは、特許図面の作成に必要な符号、包含関係、接続関係を記述するための専用記法を指します。

ブロック図、フローチャート、シーケンス図、状態遷移図を、定義・包含・接続の 3 種類の文で記述します。入力内容から図種を自動判定し、SVG、PDF、符号表 Markdown、符号表 CSV を出力します。

## 配布物

| ファイル | 内容 |
|---|---|
| `patent_dsl.html` | 配布用の単一 HTML ファイル |
| `docs/spec.md` | DSL 仕様書 |

## 主な機能

- テキストから SVG 図面を生成
- PDF 出力
- 符号表の Markdown / CSV 出力
- 日本語、英語、日英併記の表示切替
- CLI 入力と GUI 入力の切替
- 内蔵サンプルと GUI パターンの挿入
- LocalStorage による編集内容と UI 設定の保存

## 起動方法

```text
patent_dsl.html
```

ブラウザで開きます。

ソースから起動する場合:

```bash
npm install
npm run dev
```

## 基本記法

PatentDSL の文は、定義、包含、接続の 3 種類です。

### 定義

符号にラベルを割り当てます。

```pdg
10 = 制御装置 / control device
11 = CPU
12 = メモリ / memory
13 = "I/O インターフェース" / "I/O interface"
```

`/` の左側が日本語ラベル、右側が英語ラベルです。ラベルに `/`、`:`、`=`、`#` を含める場合は引用符で囲みます。

ラベルなしの符号も定義できます。

```pdg
10 =
```

### 包含

親符号と子符号の包含関係を記述します。

```pdg
100 : 10 20
10  : 11 12
20  : 21 22
```

包含文があるソースはブロック図として描画されます。

### 接続

符号間の接続を記述します。

```pdg
11 - 12
13 -> 20 : 信号 / signal
100 <-> 200 : 通信 / communication
```

演算子の前後には半角スペースが必要です。

| 演算子 | 内容 |
|---|---|
| `-` | 単線 |
| `->` | 矢印 |
| `<-` | 逆向き矢印 |
| `<->` | 双方向矢印 |
| `..` | 破線 |
| `.>` | 破線矢印 |
| `=>` | 太矢印 |

### コメント

`#` から行末まではコメントです。

```pdg
# 図1
10 = 制御装置 / control device
```

## 図種の判定

図種はソース内容から次の順序で判定されます。

| 優先 | 条件 | 図種 |
|---|---|---|
| 1 | 包含文 `:` がある | ブロック図 |
| 2 | ラベル末尾が `?` の符号がある | フローチャート |
| 3 | 符号 `*` がある | 状態遷移図 |
| 4 | `<->` または往復接続がある | シーケンス図 |
| 5 | 上記以外 | フローチャート |

シーケンス図の縦破線はライフラインです。手動で接続として入力するものではなく、シーケンス図として判定された場合に自動表示されます。

## 図形の判定

### ブロック図

通常の符号は長方形です。包含の親符号はコンテナ枠として描画されます。

### フローチャート

| 条件 | 図形 |
|---|---|
| ラベル末尾が `?` | 菱形 |
| 入次数 0 | 角丸長方形 |
| 出次数 0 | 角丸長方形 |
| その他 | 長方形 |

### 状態遷移図

| 符号 | 図形 |
|---|---|
| `*` | 黒丸 |
| その他 | 角丸長方形 |

### シーケンス図

各符号はアクターとして描画され、縦方向にライフラインが表示されます。

## GUI 入力

GUI モードでは、フォームから定義、包含、接続を追加できます。

### 符号を定義

符号、日本語ラベル、英語ラベルを入力して定義文を追加します。

形状は `四角` と `菱形` を選択できます。

- `四角`: 通常の部品または処理
- `菱形`: ラベル末尾に `?` を付与し、フローチャートの条件分岐として扱う

符号のみを入力して追加した場合は、ラベルなし定義として追加されます。

```pdg
10 =
```

### 包含

親符号と子符号を入力して包含文を追加します。

```pdg
10 : 11 12 13
```

### 接続

from、to、ラベル、線種を入力して接続文を追加します。

シーケンス図のライフラインを表示する場合は、往復メッセージを追加するか、双方向矢印 `<->` を使用します。

```pdg
100 -> 200 : 要求 / request
200 -> 100 : 応答 / response
```

## 出力

| 出力 | 内容 |
|---|---|
| SVG | 図面の SVG ファイル |
| PDF | 日本語フォントを埋め込んだ PDF |
| 符号MD | 符号表の Markdown |
| 符号CSV | 符号表の CSV |

表示言語の切替は SVG と PDF にも反映されます。

## ブロック図のレイアウト

ブロック図では次の方針で配置します。

- 子が 1 から 2 個の包含は縦 1 列に配置
- 子が 3 個以上で直列接続がある場合は縦 1 列に配置
- 子が 3 個以上で分岐、並列、スター状の接続がある場合は 2 列グリッド寄りに配置
- 同じ親コンテナ内の接続は親コンテナ内に収める
- 外部ブロックは接続先の内部ブロックに近い高さへ自動整列
- 外部接続は可視ブロックとの交差を避ける経路を優先
- 接続先が上下方向に明確にずれている場合は、横辺より上辺または下辺への接続を優先
