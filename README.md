# PatentDSL

PatentDSL は、特許明細書で使用する図面をテキストから作成する単一 HTML ツールです。

DSL は Domain-Specific Language の略で、特定用途のための記述言語を意味します。本ツールでは、特許図面の作成に必要な符号、包含関係、接続関係を記述するための専用記法を指します。

ブロック図、フローチャート、シーケンス図、状態遷移図を、定義・包含・接続の 3 種類の文で記述します。入力内容から図種を自動判定し、SVG、PNG、JPEG、PDF、PPTX、符号表 Markdown、符号表 CSV を出力します。

## バージョン

現在の配布バージョンは **v1.0.3** です。

v1.0.3 では、PPTX 出力とフローチャートの戻り線処理を追加しています。

- `PPTX`: 現在の図面を高解像度 PNG として 16:9 スライドへ配置する
- `PPTX編集`: 図面を PowerPoint の図形、線、文字へ変換し、PowerPoint 上で編集可能にする
- どちらも実描画範囲に小さな余白を付け、プレビューの余白や拡大率を出力に含めない
- フローチャートで上方向へ戻る接続は、中央の通常フロー線と重ならないよう外側レーンへ回り込ませる

v1.0.2 では、ブロック図の配線処理を更新し、次の点を改善しています。

- 外部接続がコンテナ内部を横切らないようにする
- 矢印の線本体が鏃の中まで入り込まないようにする
- 行ごとの高さを用いて、縦長要素を含むグリッドの余白を抑える
- 複数の接続が同一の箱から出る場合に、接続点と配線レーンを分散する
- 既存線と重なる候補を避け、候補が不足する場合も線分ガードを強い減点として残す
- 接続ラベルが箱、外枠、他の接続ラベルに重ならないように配置候補を評価する
- 接続ラベルは短い端点付近より、長い空き区間を優先して配置する
- 短い接続区間では、ラベルを線から少し離した候補も評価する
- 必要以上に遠いレーンへ迂回する経路を抑制する
- サンプルだけでなく、ユーザーが記述したブロック図にも同じ配線ルールを適用する
- PNG / JPEG の高解像度出力を追加し、ラスタ画像は実描画範囲に小さな余白を付けて切り出す

## 基本記法

PatentDSL の文は、定義、包含、接続の 3 種類です。

### 定義

符号にラベルを割り当てます。

```pdg
10 = 制御装置 / control device
11 = CPU
12 = メモリ / memory
13 = "I/O インターフェース" / "I/O interface"
```

空白付きの ` / ` の左側が日本語ラベル、右側が英語ラベルです。`A/D` や `I/O` のような語中の `/` はラベル文字として扱います。ラベルに ` / `、`:`、`=`、`#` を含める場合は引用符で囲みます。

ラベルなしの符号も定義できます。

```pdg
10 =
```

### 包含

親符号と子符号の包含関係を記述します。

```pdg
100 : 10 20
10  : 11 12
20  : 21 22
```

包含文があるソースはブロック図として描画されます。

### 接続

符号間の接続を記述します。

```pdg
11 - 12
13 -> 20 : 信号 / signal
100 <-> 200 : 通信 / communication
```

演算子の前後には半角スペースが必要です。

| 演算子 | 内容 |
|---|---|
| `-` | 単線 |
| `->` | 矢印 |
| `<-` | 逆向き矢印 |
| `<->` | 双方向矢印 |
| `..` | 破線 |
| `.>` | 破線矢印 |
| `=>` | 太矢印 |

### コメント

`#` から行末まではコメントです。

```pdg
# 図1
10 = 制御装置 / control device
```

## 図種の判定

図種はソース内容から次の順序で判定されます。

| 優先 | 条件 | 図種 |
|---|---|---|
| 1 | 包含文 `:` がある | ブロック図 |
| 2 | ラベル末尾が `?` の符号がある | フローチャート |
| 3 | 符号 `*` がある | 状態遷移図 |
| 4 | `<->` または往復接続がある | シーケンス図 |
| 5 | 上記以外 | フローチャート |

シーケンス図の縦破線はライフラインです。手動で接続として入力するものではなく、シーケンス図として判定された場合に自動表示されます。

## 図形の判定

### ブロック図

通常の符号は長方形です。包含の親符号はコンテナ枠として描画されます。

### フローチャート

| 条件 | 図形 |
|---|---|
| ラベル末尾が `?` | 菱形 |
| 入次数 0 | 角丸長方形 |
| 出次数 0 | 角丸長方形 |
| その他 | 長方形 |

### 状態遷移図

| 符号 | 図形 |
|---|---|
| `*` | 黒丸 |
| その他 | 角丸長方形 |

### シーケンス図

各符号はアクターとして描画され、縦方向にライフラインが表示されます。

## GUI 入力

GUI モードでは、フォームから定義、包含、接続を追加できます。

### 符号を定義

符号、日本語ラベル、英語ラベルを入力して定義文を追加します。

形状は `四角` と `菱形` を選択できます。

- `四角`: 通常の部品または処理
- `菱形`: ラベル末尾に `?` を付与し、フローチャートの条件分岐として扱う

符号のみを入力して追加した場合は、ラベルなし定義として追加されます。

```pdg
10 =
```

### 包含

親符号と子符号を入力して包含文を追加します。

```pdg
10 : 11 12 13
```

### 接続

from、to、ラベル、線種を入力して接続文を追加します。

シーケンス図のライフラインを表示する場合は、往復メッセージを追加するか、双方向矢印 `<->` を使用します。

```pdg
100 -> 200 : 要求 / request
200 -> 100 : 応答 / response
```

## 出力

| 出力 | 内容 |
|---|---|
| SVG | 実描画範囲に小さな余白を付け、単体表示しやすいサイズを指定した SVG ファイル |
| PNG | 8 倍解像度の PNG 画像 |
| JPEG | 8 倍解像度の JPEG 画像 |
| PDF | 日本語フォントを埋め込んだ PDF |
| PPTX | 図面を高解像度 PNG として 16:9 スライドへ配置した PowerPoint ファイル |
| PPTX編集 | 図面を PowerPoint の図形、線、文字へ変換した PowerPoint ファイル |
| 符号MD | 符号表の Markdown |
| 符号CSV | 符号表の CSV |

SVG、PNG、JPEG、PPTX は、SVG の実描画範囲を計算し、小さな余白を付けて切り出します。SVG はブラウザで直接開いたときに小さくなりすぎないよう、長辺が少なくとも 1600 px になる表示サイズを指定します。プレビュー領域、カード、画面上の余白、プレビュー倍率は出力に含めません。PNG と JPEG の背景は白で出力します。

表示言語の切替は SVG、PNG、JPEG、PDF、PPTX、PPTX編集にも反映されます。

PPTX には 2 種類があります。通常の `PPTX` は見た目の再現性を優先し、1 枚のスライドに図面画像を配置します。`PPTX編集` は PowerPoint 上で編集できることを優先し、SVG の矩形、円、自由図形、線、テキストを PowerPoint 図形へ変換します。細部の再現性は通常の `PPTX`、後から文言や配置を調整したい場合は `PPTX編集` を使用します。

## ブロック図のレイアウト

ブロック図では次の方針で配置します。

- 子が 1 から 2 個の包含は縦 1 列に配置
- 子が 3 個以上で直列接続がある場合は縦 1 列に配置
- 子が 3 個以上で分岐、並列、スター状の接続がある場合は 2 から 4 列のグリッド寄りに配置
- グリッド配置では行ごとの高さを使用し、特定の行にだけ縦長要素がある場合に全体の余白が過大にならないようにする
- 同じ親コンテナ内の接続は親コンテナ内に収める
- 外部ブロックは接続先の内部ブロックに近い高さへ自動整列
- 外部接続は可視ブロックとの交差を避ける経路を優先
- 接続先が上下方向に明確にずれている場合は、横辺より上辺または下辺への接続を優先
- 接続ラベルは箱、コンテナのタイトル領域、外枠、先に配置された接続ラベルとの重なりを避ける
- 短い接続区間では、ラベルを線から少し離した候補も評価する

### 配線処理

ブロック図の接続線は、直交線による配線問題として扱います。各ノード、コンテナ、既存の線、矢印の鏃を避けるべき領域として扱い、候補となる水平・垂直レーンの中から経路を選択します。

内部的には、単純な最短経路だけではなく、次の条件を加味して経路を評価します。

- 箱の内部を通過しない
- コンテナ外枠に沿って長く走らない
- 矢印の鏃に他の線が入り込まない
- 線本体を鏃の手前で止める
- 既存線との深い重なりを避け、候補が不足する場合も既存線を強い減点として扱う
- 同一の箱から複数の線が出る場合は、接続点と短いスタブを分散する
- 接続ラベルは箱や外枠をまたがず、長い空き区間に置く
- 短い接続区間では、ラベルを線から少し離した候補も評価する
- 必要以上に大回りしない

このため、最短距離だけを採用するのではなく、禁止領域とペナルティを持つ直交配線として経路を決定します。

### フローチャートのレイアウト

フローチャートでは、接続関係からランクを計算し、基本的に上から下へ配置します。上方向へ戻る接続は、中央の通常フロー線と重ならないよう、図の外側レーンへ回り込ませます。
